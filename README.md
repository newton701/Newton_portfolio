# Newton Dakua - Portfolio (React + Vite)

## Run
```bash
npm install
npm run dev        # open the URL shown (http://localhost:5173)
```

## Build for hosting
```bash
npm run build      # output in /dist (upload to Netlify, Vercel, GitHub Pages...)
npm run preview
```

## Edit your details
- All text (name, phones, email, links, skills, jobs, projects) is in `src/data.js`
- Photo: replace `public/photo.png`
- Resume: replace `public/Newton_Dakua_Resume.pdf`
- Colors: `:root` variables at the top of `src/styles.css`
